What this store will not do, and why

      
There is no box anywhere for a student's name, and there
      is no per-student balance. A record of which named child bought what is a spending and
      behavior record, and it is the one thing a class store should not create - it would sit
      in a file that gets emailed around. The store tracks stock and totals. If you want
      balances, keep them on paper where they belong to you. And if real money is involved rather
      than class money, that is school funds and it goes through the office, not through this file.
