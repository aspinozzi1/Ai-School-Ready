AI for Workload: Winning Back an Hour a Week

The stance
Hand the repetitive to the tool; keep the relational on purpose.
If a task requires knowing your kids, it's yours. If it doesn't, it's draftable.

My week audit (star = repeats + doesn't need my kids)

The template recipe (any repeating task)

  • 1 · Write it once: four-part prompt (role · task · context · format) for one real instance
  • 2 · Bracket the changes: [TOPIC], [GRADE], [DATE], [SKILL]: everything that varies week to week
  • 3 · Test it twice: run a second real instance; where it wobbles, add context. Works twice = it's a template. Save it.

Worked template · the sub plan (Ms. Rivera's)

"You are an experienced teacher writing for a substitute who has never met these students. Write a one-page sub plan for a [GRADE] class covering [TOPIC]. Context: the class routine that works is [ROUTINE]. Format: a bell-ringer, a main activity with simple numbered directions, an early-finisher task, and management notes."

More repeaters worth templating

Exit-ticket sets from any objective · station directions · newsletter shells · quiz frames with answer keys · materials lists · documentation summaries (de-identified) · progress-comment shells (personalized after, no student info in) · recommendation-letter outlines. Every working template goes in the staff doc's Workload section.

The multipliers

  • Batching: same-kind tasks in one sitting: five exit tickets in one go, not five late nights
  • The library: 30 teachers × 2 templates = 60 deleted repeaters, shared

My protected list (in ink; 3–5 lines)

The work that stays mine by decision, no matter how good the tools get. Examples: feedback conversations · grading judgment · greeting kids at the door · the calls that matter.

My recovered hour is for

The never list: never delegate the relational · never skip the review (the drift starts there) · never let the saved hour become new busywork.
The permanent rules ride along: no student personally identifiable information in public AI tools, ever. And a human reviews everything before it reaches a student or family.
