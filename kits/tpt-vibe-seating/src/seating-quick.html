A seating chart that forgets the term is a picture, not a tool. This one is a single file you double-click. It opens with a class of 24 already seated and a term of history behind it, and its Shuffle, avoiding repeats button seats your class so that nobody sits next to someone they have already sat next to — or tells you, by name, which pairs it could not keep apart.

Why it has to remember

Free chart makers are good at making a chart. None of them is a record of who sat where in October when you are deciding where they sit in February. This tool keeps that record on your own computer, uses it every time you reshuffle, and says so plainly when a small class has run out of new neighbors.

Start here

Ten minutes, start to finish

Each step ends with something you can see. If you do not see it, stop and check that step.

1

Unzip, then double-click seating-chart.html

You should see: a chart of 24 first names in a 4-by-6 grid, and under it a list of who has sat next to whom. The class is invented sample data. Press Shuffle, avoiding repeats once to watch it work, then Undo.

2

Press Set up this class

You should see: the setup screen — class name, rows and columns, a clickable room, a box for names, and a button to start a new term. No code anywhere.

3

Name the class and set the room

Type a name such as “Period 3”. Set rows and columns. Click any cell that is not a seat — your desk, a door, a cabinet. You should see: striped cells that will never receive a name.

4

Put your first names in, one per line, and press Update the class list

Paste from a spreadsheet column or type them. You should see: a count of names, and a list of every line it skipped and why — a blank line, a repeat, a “Surname, First” line. First names or initials only; page 7 says why.

5

Press Back to the chart, then Shuffle

You should see: every name seated, none in a striped cell. Drag a name onto another seat and the two swap. Or click a name, then click a seat.

6

Press Record this chart in the history, then Save to file

You should see: the history count go up, and a file download holding your class list, seating and history. Open that file next time, not the original.

Optional — have AI draft sample names to try it out
I teach a class of 24 students. Give me a list of 24 plausible first names for a class roster, one per line, nothing else on each line. No surnames. No numbering. No commentary.

The setup screen has a copy button and a box for the number. Read the names before you use them: AI gets things wrong, and a drafted list is sample data, not your class. Replace it with your real first names, typed or pasted from your own spreadsheet. Never paste your real list into a chatbot.

The feature the tool rests on

Shuffle, avoiding repeats

It reads the history, then seats your whole class so that, as far as the room allows, nobody sits beside or directly behind someone they have already sat beside this term.

How the history is made

You press Record this chart in the history when a chart goes live. That stores the pairs side by side or front-to-back. Nothing records automatically, so a shuffle you did not like never counts.

When it works

The message reads “Seated with no repeats: nobody is next to anyone they have already sat next to this term.” Undo brings back the old chart.

When it cannot — and this is not a bug

In a small class every pairing eventually exists. Then the tool does not pretend and does not hang. It seats everyone, then says:

Could not avoid 3 repeats. The grid and the history leave no way
around it, so these pairs are next to each other again:
  B & A — sat together 1 time already
  B & D — sat together 1 time already
  C & D — sat together 1 time already

What to do: start a new term (Reset the history), accept the repeats it named, or add seats. That message is the most important line in the file, because software that says “I could not” is software you can trust when it says “I did.”

Two shuffles, two jobs

ButtonWhat it does
ShuffleFills only empty seats. Nobody already seated moves.
Shuffle, avoiding repeatsReseats everyone, using the history. For a plain random chart, Clear seats then Shuffle.

Task: make it refuse

Make a class of four names in a 2-by-2 room. Shuffle, avoiding repeats, record, and repeat. You should see the refusal above, with names, within a few presses.

Real rooms

Your room is not a grid

A rigid grid is the fastest way a seating tool gets abandoned. These are the five things real rooms do.

1. Pods, a horseshoe, a bank of computers

Click the cells that are not seats on the setup screen. A horseshoe is a grid with the middle blocked. Two pods are a grid with a column blocked between them. Task: block a whole column, press Clear seats, then Shuffle: the column stays empty and the tool names who did not fit.

2. More students than seats

It will happen on day one. The tool seats who it can and names who did not fit: “Not enough seats for 2 students: D, C.” Nobody is silently dropped.

3. A new student mid-term

Add the name on a new line in the class list and press Update the class list. The history, the layout and everyone else’s seat are untouched. The new name appears under Not seated yet.

4. Two charts for one class — a normal one and a test one

The class selector at the top holds one chart per entry. Use Add another class, call it “Period 3 test”, and give it the same names. Each keeps its own seating and history, and both survive closing the page.

5. The printout is backwards

Whether a chart is drawn from the students’ side or yours is a real question. This tool prints which one it is, on the page, under the front-of-room bar. Flip left and right turns it around. Task: press Flip, then Print, and read the line under the chart.

Print gives one page: the class name, a front-of-the-room bar, and the names. No buttons, no history, no interface. Choose “Save as PDF” in the print window to keep a copy.

Make it yours

Four prompts that change the tool itself

Each one changes one real thing, and each ends with a thirty-second test. Work on the original file with the invented sample class — never on a file you have saved. A saved file holds your class list, and your class list does not go into a chatbot. Page 7 explains.

Prompt 1 — a second row at the back
Below is a single-file HTML app, a classroom seating chart. Add a way to add one more row of desks at the back without losing anyone's seat, and make the new size persist. Return the complete file, changed in as few places as possible, and tell me which lines you changed. [paste the file]
Test: a new row of empty seats appears; reload; it is still there.
Prompt 2 — color seats by how long since the student moved
Below is a single-file HTML app, a classroom seating chart that stores a list of recorded charts in its history. Color each seat by how many recorded charts that student has stayed in the same seat for: a cool color for one or two, a warm color for five or more. Add a one-line key. Return the complete file. [paste the file]
Test: the sample class shows a mix of colors.
Prompt 3 — a keep-these-two-apart list
Below is a single-file HTML app, a classroom seating chart. Add a "Keep apart" list on the setup screen where I can enter pairs of first names. Make "Shuffle, avoiding repeats" honor it, and when it cannot, say so in plain words and name the pair instead of pretending. Return the complete file. [paste the file]
Test: add two names as a pair, shuffle many times; they never touch. Then make it impossible and read the message.
Prompt 4 — the date on the print
Below is a single-file HTML app, a classroom seating chart. Put today's date under the class name on the printed page only, so a chart in a sub folder says when it was true. Return the complete file. [paste the file]
Test: Print preview shows today's date; the screen does not.

Prompt 3 is the one to run in front of colleagues. The honest answer — “it could not” — is the whole lesson about software. Save each result under a new name and keep the original. AI results differ every run; if a change breaks something, paste back the symptom and ask it to fix only that.

Where your data lives

First names, a term of history, and your own device

The tier is decided by where the data lives and who can reach it, not by whether names appear.

TierFor this tool
1 — build freelyThe grid, the row and column counts, the blocked cells, the class name, the print layout. Nothing about a child.
2 — your own deviceThe class list, the seating history, and any file you save. First names of real children, held in this browser and in the file you save. Transmitted nowhere; no account exists; no server holds a copy.
3 — stopThe same list in a shared drive, a cloud document, an email attachment, or pasted into a chatbot. The moment it leaves your machine it is a different thing.

Why first names or initials, with the reason

A chart has to be readable from the front of the room, and first names already do that. A surname adds nothing to the job and turns a classroom aid into something closer to a record.

The history is the sensitive part, not the chart

A printed chart is ordinary. A term of who-sat-next-to-whom is a small social record of a group of children. Treat the saved file like a gradebook file: your machine, your business. Do not put it on a shared drive. Follow your own district’s policy, which is the one that governs you.

How you can tell nothing is uploaded — five seconds

Turn the wifi off and open the file. Everything works. There is no upload in it because there is no network call in it: you do not have to remember a rule, because the capability does not exist.

The one place it leaves your machine is the AI prompts on page 5. Those go to the AI tool with the original file and its invented sample class, never a saved file. Build it so the wrong thing is impossible rather than so that you are careful.

The honest page

What this does not do, how it was built, and one favor

If all you need is a chart, use a free one

Free seating-chart makers are more finished and look nicer, and some save charts to an account. Free tiers cap how many students you can seat. Classroomscreen’s own pricing page lists “Save three name lists” on its free plan; Pro is $3 a month billed annually at $36, and adds “Save unlimited name lists”. If you only need a chart for the wall, keep your twelve dollars. What is different here: one file you own once, working with the wifi down, that cannot be switched off or repriced — and a term of memory.

How this is built — and what we are not claiming

The tool is one HTML file written with an AI assistant. We drove it in a real browser, offline: opening, setup, pasting a list with a blank line, a repeat and a “Surname, First” line, dragging in, out and onto an occupied seat, blocked cells, both shuffles, forcing the refusal, two classes surviving a reload, print, save, and reopening the saved file in a clean browser profile. We are not claiming it is a security product, that it suits any district’s data policy, that it works in every old browser, or that the four prompts produce the same result in every AI tool. It is a tool for one teacher’s own device.

What it does not do

It does not sync between computers. It does not know your students’ needs, so it will happily seat someone beside a person you would never pair; check every chart. It does not replace your judgment.
