Three actions · each under 15 minutes · within two days

Use it before you lose it

PD that isn't used within 48 hours mostly evaporates; that's why this sheet exists. Each action below uses something from today's session. Do all three, check the boxes, done.

ACTION 1

Do one real task with AI  ~10 min

Pick one thing already on your to-do list (a family email, a quiz, a leveled reading passage) and draft it with the AI tool from today's lab. Push back at least twice ("warmer," "shorter," "make #4 harder"). Then review it like the professional you are, make it yours, and actually use it.

ACTION 2

Run the de-identification drill  ~5 min

Think of a real student situation you'd want AI help with. On paper, not in the tool, write the prompt twice: first the unsafe way you'd naturally say it, then the safe version using the 3 moves (strip identity · generalize · describe the need, not the child). This one rep makes the habit automatic.

  • I rewrote one real prompt safely, and the safe version lost nothing that mattered
ACTION 3

Share one discovery  ~2 min

Tell one colleague, in person or in the staff chat, one specific thing: a prompt that worked, a time-saver, or a failure worth knowing about ("it invented a source — check everything"). Commitment #3 starts with you.

While you practice, the rule rides along
Never put student personally identifiable information into a public AI tool.
And a human reviews everything before it reaches a student or family.
