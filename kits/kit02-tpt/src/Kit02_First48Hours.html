Three actions · each under 15 minutes · within two days

Put the formula to work

PD that isn't used within two days mostly evaporates. Each action below uses something from today. Do all three, check the boxes, done.

ACTION 1

Run your reusable prompt for real  ~10 min

Use the template you built in the lab on the actual task it was made for, this week's newsletter, quiz, or leveled reading. Fill in the blanks, run it, iterate once, review it like the professional you are, and actually use the result.

  • I used my reusable prompt on a real task  ·  The task:
ACTION 2

Run the colleague test once  ~3 min

Before your next prompt, pause and reread it as if you were a colleague with zero context. Add the missing context or format before you hit enter. One deliberate rep builds the habit.

  • I caught something missing before I hit enter  ·  What I added:
ACTION 3

Post to the staff prompt doc  ~2 min

Your template, your name, one line about what it's for. If you already posted it in the lab, read two colleagues' entries instead and steal one technique. Commitment #4: nobody solves the same problem twice.

  • My template is in the staff doc, and I borrowed one idea from someone else's
