# Market intel — how the factory uses this folder

The Monday factory MUST read the newest `*-brief.md` in this folder before
choosing and titling the week's batch. The brief can override the Year-1
calendar row: chase demand that is live right now, rename products toward
proven search phrases, swap a planned free for one the data says teachers
are actually searching.

## Where briefs come from (fully automated)

A **Sunday research routine** (fires into the owner's persistent session,
where connectors are live) produces each brief:

1. Try Semrush first (keyword volume/competition for the coming week's
   topics). If Semrush has no API units, fall back to web research —
   TPT browse pages, seasonal teacher searches, education trend coverage.
2. **The owner's analysis spec (2026-08-24)** — every brief must include:
   - **Top 3 low-competition, high-intent terms**: candidate phrases
     ranked by buyer intent, keeping only those with roughly **under
     3,000 competing TPT products** (TPT browse pages show result
     counts — fetch `teacherspayteachers.com/browse?search=<phrase>` and
     read the count; when unfetchable, estimate from how specific the
     phrase is and say it's an estimate). Buyer intent = phrases a
     teacher types when they need a thing this week ("emergency sub
     plans template") over browsing phrases ("teaching ideas").
   - **A drafted, ≤80-char optimized title for each of the top 3**,
     ready to use or adapt in the batch.
   - **A pricing scan of the niche**: what the visible competitors
     charge for comparable page counts/formats, so the batch prices
     land at or below the niche norm for the value offered.
   - Winning formats/shapes in the niche, seasonal timing, and per-item
     title/tag recommendations, as before.
3. Commit and push, so the Monday factory (a fresh session) finds it here.

The owner can also drop exports from paid tools (Seller Spy, SpyLore,
SEOLumina — screenshots or CSVs) into this folder or into chat at any
time; fold them into the next brief. None of those tools has an API, so
their data arrives only when the owner volunteers it — never require it.

## Rules

- Briefs inform **titles, tags, descriptions, and which free to build**.
  They never override the ground rules (no student data, no future
  promises, TPT-native only, provenance line stays).
- Never copy a competitor's content or distinctive wording. Shapes,
  formats, price points, and keyword phrasing are fair game; their work
  is not.
- A brief older than 14 days is stale: the factory should proceed on the
  calendar row and note in its summary that no fresh intel existed.
